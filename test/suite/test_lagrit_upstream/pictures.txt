# pictures.txt: what to draw for a test, beyond its own AVS mesh files
# (read by pictures.py). LaGriT's decks are never edited: extra dumps
# go into a SECOND run of the deck (work/_pic_<test>), which is drawn
# but never judged. One directive per line, fields split by " | ":
#
#   TEST | color  | GLOB | COLOR          colour the test's own files
#                                          matching GLOB (see below)
#   TEST | hide   | GLOB                   do not draw these files
#   TEST | insert | REGEX | COMMAND        in the picture run, put
#                                          COMMAND after the first deck
#                                          line matching REGEX
#                                          (Python re, case-insensitive)
#   TEST | draw   | FILE | COLOR | TITLE   draw FILE (from the picture
#                                          run, or one of the test's
#                                          input files)
#   TEST | interp                          after each intrp/interpolate
#                                          command, dump the source and
#                                          the sink mesh objects; draw
#                                          each pair, the source coloured
#                                          by the source attribute, the
#                                          sink by the sink attribute,
#                                          on one scale; the test's own
#                                          files are not drawn again
#
# COLOR: mat (the material, itetclr) | node:NAME | cell:NAME |
#        attr:NAME (vertex attribute if there is one, else cell) |
#        aspect (aspect ratio, as LaGriT's quality command); a range
#        such as aspect[0,1] fixes the ends of the colour scale
# User's comments, Oct 17 2026 (test_lagrit_upstream_comments.txt).

interp_continuous | interp
